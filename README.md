# 🛠️ Laboratorio de Soporte IT y Administración de Sistemas

Bienvenido a mi repositorio de prácticas y documentación técnica. Este espacio está dedicado a registrar implementaciones, configuraciones y resoluciones de problemas en el ámbito del soporte técnico, la administración de infraestructura y las redes de computadoras.

## 📌 Objetivos del Repositorio
* Centralizar *runbooks* y guías de resolución de incidencias.
* Documentar topologías de red y configuraciones de servicios.
* Demostrar habilidades prácticas en entornos Windows, Linux y arquitecturas de red.

## 🚀 Áreas de Práctica y Conocimientos

### 💻 Sistemas Operativos y Hardware
* **Despliegue y Configuración:** Instalación, bastionado (hardening) y administración de entornos Windows y distribuciones Linux.
* **Recuperación y Diagnóstico:** Resolución de fallos críticos del sistema, recuperación de arranque (reparación de BCD, uso de `diskpart`), y validación de hardware (discos, memoria, BIOS/UEFI).
* **Gestión de Identidades:** Administración de usuarios, grupos, asignación de permisos y control de acceso (ACLs).

### 🌐 Redes y Conectividad
* **Arquitectura de Red:** Aplicación práctica de los modelos OSI y TCP/IP para el diagnóstico de conectividad.
* **Routing y Switching:** Cálculos de subnetting IP, configuración de VLANs, y despliegue de protocolos de enrutamiento (RIP, OSPF).
* **Servicios de Red:** Implementación y solución de problemas en servicios DHCP, DNS, conectividad Wi-Fi (802.11) y túneles VPN.
* **Simulación:** Diseño y validación de topologías de red utilizando Cisco Packet Tracer.

### ⚙️ Infraestructura y Servicios
* **Administración de Servicios:** Configuración de procesos en segundo plano, demonios en Linux (systemd) y despliegue de servidores web (como Internet Information Services - IIS).
* **Herramientas de Red y Seguridad:** Diagnóstico de puertos, análisis de tráfico y configuración de redes virtuales.

## 📂 Estructura del Proyecto

El repositorio está organizado en los siguientes directorios para facilitar la navegación:

* 📁 `/documentacion`: Guías paso a paso, manuales de usuario y resolución de problemas.
* 📁 `/redes`: Topologías de Packet Tracer, tablas de subnetting y configuraciones de routers/switches.
* 📁 `/scripts-y-comandos`: Recopilación de comandos útiles (CLI, PowerShell, Bash) para tareas administrativas y de diagnóstico.
* 📁 `/sistemas-operativos`: Procedimientos de instalación, recuperación y auditoría de Windows y Linux.

## 🛠️ Tecnologías y Herramientas Destacadas
* **SO:** Windows (Client/Server), Linux (Debian/Ubuntu/Kali)
* **Networking:** TCP/IP, Cisco IOS, Packet Tracer, Wi-Fi, VPNs
* **Administración:** CLI, PowerShell, Bash, IIS, Diskpart
